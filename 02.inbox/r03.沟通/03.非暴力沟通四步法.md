# 03 非暴力沟通四步法

> **核心框架·r03核心理论**。所有沟通技能都映射到这四步。
> 理论来源：马歇尔·卢森堡《非暴力沟通》
> 冲突和敏感话题怎么聊不伤人。核心：谈行为不谈人，说感受不说指责。
> 通用沟通技能，不只恋爱用。

## 四步法总览

```text
观察（客观事实）→ 感受（情绪词）→ 需要（背后的需求）→ 请求（具体可执行）
```

- **观察** = 信息层（发生了什么）
- **感受** = 情绪层（我什么感觉）
- **需要** = 需求层（我想要什么）
- **请求** = 邀请层（我希望你怎么做）

> 四步法和02的"信息+情绪+邀请"三层模型对应：观察=信息，感受=情绪，需要+请求=邀请。

## 3.1 观察 vs 评价

暴力沟通的起点是"评价"，非暴力的起点是"观察"。

| | 评价（暴力） | 观察（非暴力） |
|---|---|---|
| 例子 | "你根本不在乎我" | "你这周有三天没主动找我" |
| 性质 | 主观判断、贴标签 | 客观事实、可验证 |
| 对方反应 | 防御、反驳 | 能听进去 |

> 评价触发防御，观察引发共情。把"你总是/你从不"换成具体行为。

## 3.2 四步法详解

1. **观察**（不是评价）："你这周有三天没主动找我。"
2. **感受**："我有点失落/不安。"
3. **需要**："我希望感受到你在意。"
4. **请求**（具体、可执行）："能不能每天下班发个消息？"

**别**

- 观察夹评价："你这周三天没找我，你根本不在乎。"（又观察又评价，白搭）
- 感受变指责："你让我很生气。"（感受是"我生气"，指责是"你让我"）
- 请求变命令："你以后必须每天找我。"（请求允许拒绝，命令不许）

## 3.3 感受 vs 想法

很多人以为在说感受，其实在说想法。

| 想法（伪装成感受） | 真感受 |
|---|---|
| "我觉得你不重视我" | "我感到被忽视" |
| "我觉得你很自私" | "我感到委屈" |
| "我觉得你在敷衍" | "我感到失落" |

> 真感受是情绪词（失落、委屈、不安、开心），不是对对方的判断。

## 3.4 倾听对方

非暴力沟通不只是说，也是听。

- 听对方的观察/感受/需要/请求，即使ta表达方式很糟。
- 对方发火时，背后是没被满足的需要。别接情绪，找需要。
- 复述确认："你是说……所以你感到……？"——让对方觉得被懂。

## 3.5 什么时候用

- 表达不满、提需求、谈敏感话题。
- 对方情绪化时，你用非暴力框架接。
- 别用来吵架赢，用来让双方都被听见。

> 非暴力沟通不是"不生气"，是生气了也用对方能听进去的方式说。
