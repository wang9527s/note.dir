# 12 实战练习与案例集

> **个人练习记录 + 案例集**。把训练中的回答 + 失误 + 修正归档，供自我复盘。
> 不只记"答对/答错"——记的是**识别卡点、回应模式、退化触发条件**。
> 框架见 [06 接情绪基础](./06.接情绪基础.md)。

## 已知盲区（截至 2026-08-28）

通过 Round 1-9 训练总结：

| 盲区 | 表现 | 修正方向 |
|---|---|---|
| 默认哄模式 | 软语 + 接锅 + 想结束对话 | 强迫第 2 步陈述句命名情绪 |
| 第 2 步卡点 | 怕说错 / 怕直接，跳过承认情绪 | 用低风险入门话术（"感觉你有点 X"） |
| 从识别直接跳行动 | 跳过 2-3 步，行动显得空 | 走完 4 步再开口 |
| 情绪→需求翻译不熟 | 卡在第 3 步不知道她要什么 | 背 08 翻译表 |
| 疑问句代替陈述句 | "你是不是 X 了？"给硬撑空间 | 用陈述句"你这是 X 了" |
| **关心式哄（最隐蔽）** | 用反向夸奖（"你很厉害"）把情绪顶回去，看似接情绪实则哄 | 不要反向夸，先承认挫败感存在再问需求 |
| **第 4 步公式化** | "展"机械套成"想 X 还是想 Y"either/or 句式，像心理咨询师 | 先辨出她要什么，直接给对应展（倾诉/分享/陪伴/建议） |
| 退化触发 | 措辞稍变场景就掉回哄 / 解释 / 关心式哄 | 实战前先在心里说第 2 步 |

> **核心卡点**：怕说错 → 跳过第 2 步 → 直接给行动 → 显得是哄。
> **核心修正**：实战前**先在心里说出第 2 步陈述句**再开口。光这一步把命中率从 30% 拉到 70%。

## 案例填示范例（今天好累）

> 用 [03 心智模型-听辨接展·案例分析模板](./03.心智模型-听辨接展.md#十一聊天案例分析模板) 填的第一个完整范例。从 [03.心智模型-听辨接展](./03.心智模型-听辨接展.md) 移入。

**对方**

> 今天好累。

### ① 事实

今天经历了一些消耗。

### ② 情绪

可能：

* 疲惫
* 烦躁
* 委屈

### ③ 需要

可能：

* 被理解
* 被陪伴

### ④ 连接邀请

可能是在说：

> 我愿意告诉你我的状态，
> 你愿意关心一下我吗？

### ⑤ 接住

> 「听起来今天真的挺累的。」

### ⑥ 延展

> 「发生什么了？」

或者：

> 「今天是不是特别忙？」

### 不同的回应路径

- 如果她继续详细说 → 继续倾听。
- 如果她只是简单回复 → 不强行追问。
- 如果她问怎么办 → 再进入建议。

## 经典案例完整推演（Round 1-9 对应）

> 以下是7类隐藏信号的完整对话推演，对应训练历史摘要中的Round 1-9。每个案例包含：场景对话、4步拆解、陷阱提醒。

### 案例1：求关注型（深夜"睡了吗？"）

```text
ta（晚 11 点）：睡了吗？
你：还没，刚忙完 X，你呢怎么这么晚还没睡？
```

| 步 | 内容 |
|---|---|
| 1. 识别 | 此刻想你了，求陪伴 |
| 2. 承认 | （用反问代承认）"你呢怎么还没睡" |
| 3. 需求 | 求连接 |
| 4. 行动 | 分享自己此刻状态 + 反问 |

> **陷阱**："回怎么了"——把球踢回去，等于让 ta 必须再前进一步才能开始对话。

### 案例2：最后通牒型（异地"算了，你忙你的吧"）

```text
ta：算了，你忙你的吧。
你：不算。刚忙完，现在到你了，视频一下？
```

| 步 | 内容 |
|---|---|
| 1. 识别 | 已放弃，求"不算" + 求"我重要" |
| 2. 承认 | "不算"直接翻案 |
| 3. 需求 | 确认"我对你不是负担" |
| 4. 行动 | 给当下可做的事 |

> **陷阱**：解释"我刚才在忙 X 因为 Y"——讲理 = 把对话变成辩论，ta 要的不是原因，是"我重要吗"。

### 案例3：反讽型（"行吧，你开心就好"）

```text
你（提议周末陪 ta）
ta：行吧，你开心就好。
你：你这一句"开心就好"明显是不开心了。我刚才说成"我周末过去"，听着像我自己想去办事顺便捎上你——其实是想见你，话没说好。你这个周末想干嘛？我可以全听你的。
```

| 步 | 内容 |
|---|---|
| 1. 识别 | 反讽 + 测试 + 暗示"你只顾自己开心" |
| 2. 承认 | 点破反讽"明显是不开心了" |
| 3. 需求 | 求被考虑、求决定权 |
| 4. 行动 | 降姿态（不认错） + 反转动机 + 给选择权 |

> **陷阱**：① 真把"行吧"当同意 ② 立刻认错"对不起对不起"

### 案例4：复合情绪型（"你最近是不是工作挺顺利的"）

```text
ta：你最近是不是工作挺顺利的？
你：你这是觉得我顺利了就把我忘了——这几天是忙，但不顺利我也想到你。你最近怎么样？
```

| 步 | 内容 |
|---|---|
| 1. 识别 | 委屈 + 比较中（顺利了不要我） + 求关注 + 试探 |
| 2. 承认 | 点破试探 |
| 3. 需求 | 确认"顺利 / 不顺利我都惦记你" + "你也问问我" |
| 4. 行动 | 一句带过忙 + 反转暗示 + 反弹关心 |

> **陷阱**："嗯还行，刚做完一个项目"——只答字面，完全错过情绪层。

### 案例5：反向陷阱型（"我今天被领导骂了"）

```text
ta：我今天被领导骂了。
你：这一天被搞得很烦吧——跟我说说，怎么了？
```

| 步 | 内容 |
|---|---|
| 1. 识别 | 求倾诉 / 求被听见 / 测试脆弱性是否被欢迎 |
| 2. 承认 | "被搞得很烦吧"陈述句命名情绪 |
| 3. 需求 | 求被听见（不是求建议 / 求安慰） |
| 4. 行动 | 邀倾诉"跟我说说" |

> **陷阱**："太过分了！要不要我帮你出气？请你吃好吃的压压惊"——三个动作都是让情绪消失，没有一步陪 ta 待在不舒服里。

### 案例6：伪装自责型（"都是我不好，行了吧？"）

```text
ta：都是我不好，行了吧？
你：你这一句"行了吧"明显是不想聊了——那先停，等你想说再说。不是来分锅的。
```

| 步 | 内容 |
|---|---|
| 1. 识别 | 厌烦 + 用自责当盾牌撤退 + 等你接锅 |
| 2. 承认 | 点破盾牌"不想聊了" |
| 3. 需求 | 求"停止争对错，让我喘口气" |
| 4. 行动 | 给停战空间，但不接锅、不关闭 |

> **陷阱**："不是你的错，我也有问题"——接锅 = 承认"是我逼 ta 这么说"。

### 案例7：暗示期待型（"你朋友生日你都记得"）

```text
你（随口）：我给小李过了生日。
ta（沉默几秒）：哦，你朋友生日你都记得。我都忘了自己生日了。
你：你这一句明显是觉得我没把你生日当回事——你的生日是 X 月 X 日，我当然记得。那周末我安排——
```

| 步 | 内容 |
|---|---|
| 1. 识别 | 委屈 + 比较中（朋友 vs 我） + 期待被像朋友那样对待 |
| 2. 承认 | 点破暗示"觉得我没把你生日当回事" |
| 3. 需求 | 确认"我在你那里比朋友重要 / 你会记得我的" |
| 4. 行动 | 报出 ta 生日日期（具体证据） + 给安排 |

> **陷阱**：① 跟着自嘲"我也是忘性大" ② 辩解"我记的是日历提醒"

## 练习记录

### Round 10 — 婉拒 + 试探（追求阶段）

**场景**：你和对方聊了一周多，感觉还不错。今天你约她周末出来吃饭，她回：

> "这周末有点事，下次再说吧~"

**问题**：
1. 字面 + 隐藏信号（至少 2 层——她是真有事还是婉拒？怎么判断？）
2. 陷阱回应：① 追问"什么事啊" ② 立刻再约"那下周呢？" —— 各自为什么错？
3. 正确回应思路（4 步框架，注意追求阶段分寸）

**回答**：
1. 婉拒；没给出具体原因和下次时间作为判断依据
2.1 本来就是借口
2.2 婉拒了，这样会把对方推得更远
3. "好的你先忙，后续有时间可以再约。"（~ 表示还是有一定好感的）

**点评 + 修正**：

**Q1** — 抓对核心（婉拒 + 没具体原因/时间）✅。漏：
- **"~" 应在 Q1 解读**（你放 Q3 了）：~ 表示软拒绝、保留友好，不是硬甩脸
- **"再说吧" 的开放性 = 拖延/回避**，不是真"改天"。真有事会说"下周 X 如何"
- **关系未确认 → 她没义务给具体原因**

**Q2** — 方向对但太笼统：
- 2.1 追问"什么事啊"：逼她编更具体借口 + 信号不信任 + 把对话推向"你证明你有事"的奇怪方向
- 2.2 立刻再约"那下周呢"：显得急/低姿态 + 没给她台阶（她刚说"再说"你立刻逼她定下次）+ 追求压力加码

**Q3** — 方向对（不追问、不施压），但有一处过线：
- ❌ "后续有时间可以再约" = **主动加码追求**。她刚说"再说"你回"再约" = 没接住她的退，反而加码

更好版本：
- "好勒，那你先忙你的，周末愉快~"
- 或："好嘞，那你先忙，改天你方便了再说~"

**4 步框架在婉拒场景的变体**（4 步原框架适用于"对方表达情绪"场景，婉拒需要变体）：

| 步 | 婉拒场景变体 |
|---|---|
| 1. 识别 | 婉拒 + 友好（~）+ 没具体原因/时间 |
| 2. 接受退 | 不显性承认情绪（她没在表达情绪），直接接受退 |
| 3. 需求 | 她要"不尴尬地保持距离、留余地" |
| 4. 行动 | 简短接受 + 友好收尾 + 把球给她 |

> 关键差异：情绪型回应 = 命名她的情绪；婉拒型回应 = 接受她的距离。**不要在婉拒场景硬套 4 步的第 2 步承认情绪**——她没在表达情绪，是在创造距离。

### Round 11 — 脆弱分享（追求阶段）

**场景**：你和对方聊了一周多，感觉还不错。晚上她突然发：

> "有时候觉得自己挺没用的"

**问题**：
1. 字面 + 隐藏信号（这是好感信号还是单纯吐槽？）
2. 陷阱回应：① "别这样想" ② "你怎么了？发生什么事了？" —— 各自为什么错？
3. 正确回应思路（4 步框架，第 2 步用陈述句）

**回答**：
1. 暴露脆弱、展示真实的自己、想看看我对她真实的表现
2.1 否定对方，相当于关门了
2.2 把情绪变成了事情
3. "是啊我们都是普通人，超人也有脆弱的时候。你的xxx表现很厉害了哦"

**点评 + 修正**：

**Q1** — 抓对核心（暴露脆弱 = 好感信号 + 想看你的反应）。补：追求阶段她愿意跟你暴露脆弱本身就是**动心线索**（吐槽可以找闺蜜，找你 = 想让你接住）。两层要分清：
- 字面层：自我否定、挫败感
- 隐藏层：想被看见（挫败被接住）+ 测试你是否在乎（滑动门时刻）

**Q2.1** — 方向对（否定+关门）。补：这是**硬哄**（通过否定让情绪消失）"别这样想"= "你的情绪不合理"；还有俯视感——你站她上面评价她感受。

**Q2.2** — **很好**。"把情绪变成了事情"精确。补：接了信息层漏了感受层（04 回应三层次）；还**逼她解释**——"发生什么事了"强迫她为情绪找理由，她可能只是有这感觉没具体事，被问反要编理由。

**Q3** — **退化回关心式哄**（Round 6 / Round 8 重演）：

| 回应 | 拆解 |
|---|---|
| "我们都是普通人" | ✅ 正常化（好） |
| "超人也有脆弱的时候" | ⚠️ 有点说教感（居高临下告诉她"连超人都会"） |
| "你的xxx很厉害了哦" | ❌ **关心式哄**——通过反向夸奖把她的"没用"顶回去 = 没承认她此刻挫败，用夸让情绪消失。也是俯视感（你是裁判给她打分） |

**漏掉的**：第 2 步陈述句命名情绪（整段没出现"你这是 X 了"）/ 第 3 步回应需求（她要被看见不是被夸厉害）/ 第 4 步问需求给选择权。

> **关心式哄最隐蔽**——看似在接情绪（你还在夸她），实际还是哄（通过反向夸奖让情绪消失）。Round 6/8 的同构坑，措辞变了内核没变：**怕她难受 → 想让她快点好 → 用夸的把情绪顶回去**。

**4 步完整版**：

| 步 | 内容 |
|---|---|
| 1. 识别 | 暴露脆弱（动心线索）+ 自我否定 + 想被看见 |
| 2. 承认（陈述句） | "你这是把自己否定了一顿啊" / "听着像被什么戳到，自我怀疑了一波" |
| 3. 需求 | 她要被看见（挫败感被接住），不是被夸"厉害" |
| 4. 行动 | 简短接住 + 问需求 + 不讲道理 |

**更好版本**：
- "你这是把自己否定了一顿啊。这会儿是想说说，还是就想有人陪着待会儿？"
- "这话听着像被什么戳到了。我没走，想说我听着，不想说就陪你待会儿。"

> 公式：**陈述句命名挫败 + 问她要倾诉还是陪伴**。**不要反向夸**——"你很厉害"是把她的情绪顶回去；先承认挫败感存在，再问她要什么。
>
> **退化触发复盘**：措辞变了（"超人也会"vs"好了好了是我没注意"），但内核同构——都是"想让她快点好"。**卡顿技巧**：开口前先在心里说出第 2 步陈述句（"你这是 X 了"），这一步没说出来，后面就退化。

### Round 12 — 催相亲（追求阶段·混合需求）

**场景**：你们聊得不错，她突然发：

> "我妈又催我相亲了 烦死了"

**问题**：
1. 字面 + 隐藏信号（她为什么跟你说这个？只是吐槽吗？）
2. 陷阱回应：① "那你就去见见呗" ② "你就跟你妈说不想去" —— 各自为什么错？
3. 正确回应思路（4 步框架，重点考第 4 步展分叉——先辨她要什么再展）

**回答**：
1. 看我对她有没有意思
2.1 不在乎她，没体会到她情绪
2.2 只有解决办法，没有情绪
3. "对啊 这种真的烦，能不能不去啊，和家里人说没感觉或者见面敷衍下"

**点评 + 修正**：

**Q1** — 抓到**试探层**（看我在不在乎她），这一层存在。漏：
- **字面层**：烦 = 求倾诉/被理解（最基本，整段没接住）
- **隐藏层 1**：她愿意跟你说被催 = 滑动门时刻（把你当可以倾诉的人，好感信号不是测试）
- ⚠️ **追求阶段警惕过度解读"试探"**：她可能就是吐槽 + 分享生活。把"她在测试我"读太重会让你过度策略化。**安全读法**：默认倾诉 + 分享，回应里留余地接住可能的试探即可。

**Q2.1** — "那你就去见见呗" 方向对（没接情绪）。补：
- 听起来像你不介意她被相亲走——她若真在试探，这是 worst answer
- "呗"语气敷衍，把她的烦轻量化
- 漏了倾诉需求（她不是问"我要不要去"）

**Q2.2** — "你就跟你妈说不想去" 你说"只有解决办法，没有情绪"——**精确**。补：
- **教她做事**（居高临下告诉她怎么处理她妈）
- **不现实**——她要能直接说"不想去"就不会烦了
- **跳过情绪直接给方案** = 03 回应三层次的"接信息层"，漏感受层

**Q3** — **又掉进 Q2.2 的坑了**——知行分离：

| 回应 | 拆解 |
|---|---|
| "对啊 这种真的烦" | ✅ 接情绪（弱，"对啊"是附和不是命名；更好："你这是被催烦了"） |
| "能不能不去啊" | ⚠️ 还在解决方案层 |
| "和家里人说没感觉" | ❌ 给建议 1 |
| "或者见面敷衍下" | ❌ 给建议 2（+ 教她敷衍家人，越界） |

> **Q2 刚识别完"只给解决办法没情绪"是错的，Q3 自己又给出 3 条建议**。这是"知道陷阱 ≠ 避免陷阱"的退化——知行分离。
>
> **退化触发复盘**：和 Round 11 关心式哄同构——都是"怕她烦 → 想帮她快点解决 → 跳过情绪直接给方案"。**卡顿技巧没生效**——开口前没在心里说出第 2 步陈述句，所以展分叉没走，直接跳到行动。

**4 步完整版**（先辨再展，别直接给建议）：

| 步 | 内容 |
|---|---|
| 1. 听 | 妈催相亲，她烦 |
| 2. 辨 | 情绪=烦/压力；需要=**被理解+被支持**（不是建议）；连接邀请层=分享生活 + 可能藏看你怎么反应 |
| 3. 接（陈述句） | "你这是被催得烦了" |
| 4. 展（辨出要倾诉，不要给建议） | "你怎么回她的？" / "你妈一般怎么催的？" / "听上去你妈挺执着的" |

**更好版本**：
- "被催得烦了吧——换我也想躲。你怎么回她的？"（Validation 三步：看见"烦"+理解"被催"+确认"换我也想躲" → 展·倾诉）
- "你这是被催到想原地消失了。你妈一般怎么催？"（陈述句命名 + 展·倾诉）

> 公式：**陈述句命名烦 + Validation 三步 + 展·倾诉**。**别给建议**——她没问"怎么办"，她在烦。给建议 = 把她的烦变成"问题"让她解决 = 加压。
> 只有她明确问"那你觉得我应该怎么办"才进展·建议路径。
>
> **退化规律**：Q2 识别陷阱 ≠ Q3 避免陷阱。**知行分离是 Round 12 暴露的新盲区**——能在分析时点出陷阱，但开口时仍掉进去。**修正**：开口前先在心里走完第 2 步陈述句 + 第 4 步辨出她要什么再展。

## 附录：沟通技巧案例集

> 从理论文件中提取的完整案例推演，集中归档。涵盖沟通模型、表达技巧、需要与请求三大类。

#### A. 沟通模型类（4个）

**案例A1：编码错误（想的和说的不是一回事）**

> 背景：他加班到很晚，她发"你在加班吗"。他想表达"辛苦但想到你挺暖"，结果说成了反话。

```text
她：你在加班吗？
他：是啊，累成狗。（本想表达：累但看到你消息挺高兴）
她：那你早点休息，不打扰了。（解码成：他烦我了，赶我走）
他：嗯。（以为她会说"加油"，结果她撤了，自己也蒙）
```

**断点定位**

| 环节 | 内容 | 问题 |
|---|---|---|
| 编码 | "累成狗" | 想说"累了但你在挺好"，编码成纯抱怨 |
| 传递 | 文字丢语气 | 没补上"但你找我我挺开心"那层 |
| 解码 | 她听成"嫌我烦" | 按自己经验理解成拒绝信号 |
| 反馈 | "嗯"单字 | 双方都没给确认，误会滚下去 |

**修复版**（编码层就改对）

```text
她：你在加班吗？
他：在，今天挺满的。不过你发消息来我还挺高兴，歇口气。（事实+感受，编码完整）
她：哈哈那你加油，弄完早点睡。
他：嗯，你也早点。（对方接住了，对话流动）
```

> 关键：先想"我想让对方接收到什么"，再用对方能解码的方式说出来。反话、省略、单字都易触发解码错误。

**案例A2：三层表达完整推演**

> 同一件事，只到事实层 vs 到邀请层，对话走向完全不同。

**只到事实层**
```text
他：今天去看了个展。
她：哦，什么展。
他：一个当代艺术的。
她：哦。
```
> 死了。她只能"哦"，因为没给情绪接话位。

**到感受层**
```text
他：今天去看个展，意外地挺戳我。
她：怎么戳了？
他：有几件作品说到一些我自己都没想清楚的事。
```
> 活了。感受层给了她追问的钩子。

**到邀请层**
```text
他：今天去看个展，意外地挺戳我。你平时看展多吗？
她：不多诶，但好奇是什么类型的。
他：偏当代的，下次一起去？我可以带你逛逛。
```
> 推进了。邀请层直接把球抛回去，还顺带约下次。

> 练法：每次表达完自检——这句话到第几层？对方接了能接什么？新手停在事实层，刻意练到感受层。

**案例A3：节奏对比**

> 同样内容，节奏不同，结果天差地别。

**节奏差版**（一次倒太多）
```text
他：今天发生好多事。早上开会跟领导吵起来了，因为我那个方案他根本没看就否了，然后下午又接到客户投诉说交付有问题，但那个明明是上周就交付的他们自己没确认……
她：……（不知道接哪句，干脆回表情）
```
> 一长串=没留对方插嘴位=单向输出，对方接不住。

**节奏好版**（一句一停）
```text
他：今天跟领导吵起来了。
她：啊？因为啥？
他：我那个方案他没看就否了。
她：那确实气人。
他：下午还接了个客户投诉，更离谱……（停，等她追问）
她：又咋了？
```
> 一句一停，对方每句都有接话位，对话自然流动。

**案例A4：文字vs语音的传递损耗**

> 同一句"随便你"，三种载体意思完全不同。

| 载体 | "随便你"的解码 | 原因 |
|---|---|---|
| 文字 | "他不高兴了/敷衍" | 没语气，默认往负面读 |
| 语音（平静） | "真的都行" | 听得出没情绪 |
| 语音（带叹气） | "有点不爽但不想说" | 语气暴露真实状态 |
| 见面（笑着说） | "都听你的" | 表情+语气，最准 |

> 结论：重要情绪别只用文字。"随便你""嗯""哦"这类词在文字里默认被读成负面，要么补情绪词，要么换语音/见面说。

#### B. 倾听与表达类（6个）

**案例B1：回应三层次完整对话**

> 同样对方说"今天被领导骂了"，三个层次回应，对话走向不同。

**敷衍层**
```text
她：今天被领导骂了。
他：哦。
她：……嗯。
```
> 终结。对方不说了。

**接信息层**
```text
她：今天被领导骂了。
他：因为啥？
她：一个方案没改对。
他：那你改了没。
她：改了。
```
> 能聊但不热。像查户口，情绪没接住。

**接情绪+追问层**
```text
她：今天被领导骂了。
他：啧，听着就憋屈，当着别人面还是单独的？（先接情绪，再追问细节）
她：当着全组的面，气死我了。
他：当众说这事确实伤，你当时怎么忍住的？
她：（开始倾诉）我差点当场怼回去……
```
> 对方想多聊。先接情绪（憋屈），再追问给话头。

> 公式：**情绪词 + 追问细节/感受**。"啧/难受/换我我也…"+ "因为啥/后来呢/当时啥感觉"。

**案例B2：话题转接链条**

> 一个话题聊尽了，怎么自然转到下一个。借词转+联想转+场景转连用。

```text
他：周末去爬了趟山。
她：哪座？累不累。
他：城西那个，累瘫了。（话题A：爬山，聊到尽头）
她：哈哈你体力不行。
他：借词转→说到体力，我最近是真虚，上下楼都喘。（话题B：健身）
她：你不是办了卡吗，去过几次？
他：联想转→卡办了两年去三次，主要那家离太远。说到远，你住那边去过没？（话题C：她住处附近）
她：去过啊，那家附近有家面馆特好吃。
他：场景转→面馆？下周一起去，爬完山正好补一顿。（话题D：约下次，落到行动）
```

**转接手法标注**

| 转接点 | 手法 | 抓的词 |
|---|---|---|
| A→B | 借词转 | "体力" |
| B→C | 联想转 | "离太远"→她住处附近 |
| C→D | 场景转 | "面馆"→一起去 |

> 顺的转接像水流：每个新话题都从上一句自然长出来，不是硬切。硬切=双方都尴尬。

**案例B3：讲故事完整推演**

> 同样"今天遇到个奇葩同事"，干讲 vs 会讲。

**干讲版**（流水账）
```text
他：今天同事做了件奇葩事。
她：啥事。
他：他把邮件发错人了。
她：哦。
```
> 没钩子、没细节、没落点，对方"哦"完就没了。

**会讲版**（钩子→经过→落点）
```text
他：今天我差点社死，替同事背了个锅。（钩子：先抛反差结果）
她：啊？咋了。
他：他群发邮件把方案附件发成了表情包，客户回了个问号。（经过：具体到画面）
她：哈哈哈离谱。
他：关键是群里有领导，他第一反应是问我"附件是不是你帮我加的"。（转折）
她：这也太坑了吧。
他：我当时整个呆住，胃都凉了。（落点：感受收尾）
她：那后来呢，领导怎么说？
```

**结构拆解**

| 部分 | 内容 | 作用 |
|---|---|---|
| 钩子 | "差点社死，替同事背锅" | 抛反差，勾好奇 |
| 经过 | "发成表情包，客户回问号" | 具体画面，有细节 |
| 转折 | "第一反应问我" | 制造冲突，情绪升 |
| 落点 | "胃都凉了" | 感受收尾，给对方反应位 |

> 关键：先把结果抛出来勾住，再倒回去讲经过，最后落到感受。别按时间流水账。

**案例B4：画面感对比**

| 抽象 | 画面 | 为什么画面更好 |
|---|---|---|
| "今天加班很晚" | "加到地铁都没人了，整条街就我一个在走" | 对方脑里有图 |
| "那家店排队很长" | "排到我跟前面大哥聊了半小时，差点加微信" | 有画面还带幽默 |
| "很冷" | "呼出来的气能看见，手掏出来三秒就缩回去" | 具体可感 |
| "很饿" | "饿到闻见隔壁炒饭都在感动" | 夸张基于真实感受 |

> 练法：每次想用形容词（很累/很好/很差），逼自己换成一个动作或画面。

**案例B5：潜台词实操对话**

> 把"字面+情绪+上下文+行为模式"套到一个真实对话。

```text
她：我们还是顺其自然吧。
```

**四步拆解**
| 维度 | 内容 |
|---|---|
| 字面 | 顺其自然，慢慢来 |
| 情绪 | 平淡、略回避 |
| 上下文 | 你刚追得有点紧，提了确认关系 |
| 行为模式 | 最近回消息变慢，拒绝两次邀约 |
| **真实含义** | 不想确认关系，也不想继续推进，用"顺其自然"给台阶 |

**回应（别戳破，给台阶）**
```text
他：好，我尊重你的节奏。（接受+不施压）
她：嗯。
他：那先这样，有空一起玩。
```
> 听懂了就别追"所以你到底喜不喜欢我"。戳破=对方尴尬=关系更僵。体面收，留余地。

> 潜台词的最高境界：对方不用把话说绝，你已经接收到信号并做出合适回应。

**案例B6：男女表达错位修复**

> 男女表达/接收方式不同，错位怎么用对话修复。

**错位现场**
- 他默默修好她的电脑，觉得"我都为你做了这么多"
- 她觉得"他都不说爱我"
- 错位：他用"行动"表达，她要"言语确认"

**修复对话**（承认差异，用对方要的方式补）
```text
他（意识到错位）：我好像一直用做事表达，不太会说话。你那边需要的是我多说点、多陪点是吗？
她：嗯……其实你做的我都看在眼里，就是有时候想听你说。
他：那我试试。今天挺想你的。（行动人开口说一句）
她：（笑了）那你多说说。
```

| 步骤 | 他做的 | 原理 |
|---|---|---|
| 觉察 | "我好像一直用做事表达" | 承认自己的表达方式≠对方的接收方式 |
| 核对 | "你那边需要的是…是吗？" | 直接问，比猜准 |
| 补 | "今天挺想你的" | 用对方要的方式（言语）补，不是坚持"我这样够了" |

> 关键：承认差异，用对方要的方式补，不是坚持"我这样已经够了"。

#### C. 需要与请求类（3个）

**案例C1：需要识别完整推演**

> 背景：他最近总因为小事发火，自己也说不清为什么。用"感受→需要"反推。

**第一步：抓感受**
```text
情境：她周末跟闺蜜出去玩，没回他消息。
他的感受：烦躁、有点堵。
```

**第二步：问"这个感受背后我需要什么"**

| 感受 | 可能的需要 | 哪个对 |
|---|---|---|
| 烦躁 | 需要被关注 | 她出去玩本身没碍着他，更像这个 |
| 堵 | 需要安全感、确定性 | 没回消息=不确定她在干嘛=失控感 |
| 有点委屈 | 需要被重视 | 她选了别人没选我 |

> 反推下来：他的真需要是**被关注+确定性**（她没回消息让他不确定自己重不重要）。

**第三步：据此表达请求**
```text
他（找到需要后）：周末你出去玩我挺开心，就是有时候半天没消息我会有点不安。能不能玩的时候偶尔看一眼手机，回个表情也行？
```
> 需要找到了，请求就具体了。不是"你别老不理我"（评价+指责），是"半天没消息我不安，能不能偶尔回个表情"（感受+需要+具体请求）。

> 没找到需要的人只会说"你又出去玩，根本不在乎我"——既没说清自己要什么，也把对方推远。

**案例C2：请求 vs 命令对话对比**

> 同一个需求（想被联系），三种表达，对方反应天差地别。

**命令版**
```text
他：你以后必须每天找我，不然我怎么知道你在乎。
她：我有时候真忙，顾不上。
他：忙到发个消息都没时间？
她：（防御，开始解释/对抗）
```
> 不许拒绝=命令。对方进入防御模式，要么对抗要么敷衍。

**模糊请求版**
```text
他：你能不能多关心我一点？
她：……（不知道怎么做）好？
```
> 不具体、不可执行。对方不知道"多关心"具体是什么，答应了也没法落地。

**有效请求版**（具体+可执行+正向+允许拒绝）
```text
他：能不能每天下班发个消息，哪怕一句"到家了"也行？
她：这个可以。
他：要是哪天实在太忙漏了也没事，我看到就行。
```

**三要素自检**

| 要素 | 命令版缺什么 | 有效版有什么 |
|---|---|---|
| 具体 | "多关心我"模糊 | "下班发个消息" |
| 可执行 | 不知道怎么做 | "发一句到家了" |
| 正向 | 隐含指责 | 说想要什么 |
| 允许拒绝 | "必须""不然" | "漏了也没事" |

**案例C3：请求被拒后的处理**

> 请求被拒≠不爱。可能是做不到或有别的需要。

```text
他：能不能周末别总加班，陪我一下？
她：这阵子项目真走不开，我自己也想喘口气。
```

**错的处理**（把拒绝当否定）
```text
他：你就是工作比我重要。（把拒绝=不爱）
她：（更不想理）
```

**对的处理**（讨论替代方案）
```text
他：理解，项目紧我也经历过。那这周末你忙完能不能抽个晚上，哪怕一起吃个饭？
她：周六晚应该可以。
他：行，那就周六晚。
```
> 被拒后问"这个对你有困难吗，有没有其他方式"——把请求当协商，不是当命令。允许对方拒绝，关系才安全。
