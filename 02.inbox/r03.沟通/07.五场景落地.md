# 07 五场景落地

> **场景应用**。把前面的技巧映射到具体场景：线上聊天、约会对话、安慰人、拒绝人、吵架现场。
> 基础见 02-06，本篇讲"在X场景怎么说"。

## 7.1 线上聊天

**开场**：别"在吗""吃饭了吗"。用具体事物+情绪开场。

- 别："在干嘛？"
- 宜："刚看到一个东西想起你（发图）" / "今天被一个客户折磨到想原地退休"

**节奏**：见 02 基础。别秒回打卡，频率匹配对方。

**冷了**：别硬续。自然收（"先去忙啦"），下次用新话题开。

**引线下**：聊到具体事物时自然引（见 04 话题的转接）。

> 线上文字丢情绪，用词要更用力一点补回来（见 04 情绪表达）。

## 7.2 约会对话

**开场破冰**：用当下环境或共同点，别查户口。

- "这家店你来过吗？朋友推荐的。"
- "你今天过来路上还顺吗？"

**深入**：按话题梯度推进（04 话题），日常→兴趣→经历。别一上来就深层。

**冷场**：接受几秒沉默，喝水看环境，自然引新话题。别慌着硬找话。

**让对方多说**：多问开放性问题，对方说的时候别打断、别抢主角。

**收尾**：表达感受+留下次钩子。"今天聊得挺开心的，下次再去试试那家。"

## 7.3 安慰人

**核心**：先接情绪，别给建议。对方要的是被听见，不是被解决。

**做**

- 倾听，别打断。
- 复述确认："所以你是说……？"
- 共情："换我我也难受。"
- 问需求："你想说说，还是想我陪你待会？"

**别**

- "这有啥好难过的"（否定情绪）
- "你应该……"（急着给方案）
- "我之前更惨"（抢主角、比惨）
- 讲大道理（对方情绪没下去，道理听不进）

> 情绪下去了再问"要不要一起想想怎么办"。没下去前别给建议。

## 7.4 拒绝人

**核心**：明确+善意+不拖。

**做**

- 直接说清，别绕弯让对方猜。
- 肯定对方，再说不合适。
- 简短，别长篇解释（解释越多越像借口）。
- 一次说清，别留"以后再说"的暧昧。

**话术**

- "谢谢你对我好，但我感觉我们不太合适，不想耽误你。"
- "你人挺好的，但我没有那种感觉，不想勉强。"

**别**

- "你人很好但是……"只剩"你人很好"——对方会以为是时机问题。
- 拒了还说"可以做朋友"——给假希望。
- 拖着不拒，等对方自己退——消耗双方。

## 7.5 吵架现场

**核心**：降火+对事不对人。非暴力沟通四步法见 03，戈特曼四骑士见 r02。

**做**

- 先暂停情绪："我有点上头，先缓一下，等会再说。"（暂停可以，要约好回来谈）
- 谈行为不谈人："你今天没回我"不是"你从来不重视我"。
- 说感受不说指责："我感到被忽视"不是"你让我很难受"。
- 一次吵一件事，别翻旧账。
- 吵完主动修复，哪怕问题没全解。

**别**

- 冷战/消失（冷暴力，比吵更伤）
- 人身攻击、贴标签
- 比较贬低（"你看别人家……"）
- 情绪勒索（"不X就分手"）

> 吵架不是赢对方，是让双方都被听见、关系还能继续。

## 7.6 通用原则

- 先接情绪，再接信息（所有场景通用）。
- 让对方多说，自己少抢。
- 沉默比硬填强，收尾比硬续好。
- 不确定对方状态时，直接问："你现在想聊还是想静静？"
