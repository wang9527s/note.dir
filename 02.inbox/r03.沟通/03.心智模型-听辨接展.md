# 03. 心智模型：听 → 辨 → 接 → 展


## 一、整体框架

### 一条信息的五层结构（分析工具）

```text
对方说的话
    │
    ▼
① 发生了什么？──────── NVC：观察
    │
    ▼
② 她感受到了什么？──── NVC：感受
    │
    ▼
③ 为什么会这样？────── NVC / EFT：需要与深层情绪
    │
    ▼
④ 她在向我发出什么？── Gottman：连接邀请
    │
    ▼
⑤ 我如何回应？──────── Validation：确认与接住
    │
    ▼
继续探索 / 陪伴 / 庆祝 / 解决问题
```
## 二、听 —— 接事实，不评价

对方说"你今天都没怎么找我"——

- **事实**：今天联系比较少

不要一上来反驳解释（"我哪里没找你？"）。先问：**这句话为什么会被说出来？**

## 三、辨 —— 内部识别，对方看不到

> 你在脑子里快速过一遍：她现在是什么情绪？背后有什么需要？是在向我发出连接邀请吗？

### 3.1 识别情绪：感受 ≠ 想法

**容易伪装成感受的想法**（含对他人行为的判断）：
- "我感觉你不在乎我" → 这是想法，不是感受
- "我觉得你忽视我" → 这是判断，不是感受

**把"想法" 转为 感受**：

如果我认为「他不在乎我」，那么我真正的情绪是什么？→ 失落 / 委屈 / 害怕 / 孤独。

> **真正的感受**（情绪词）：开心 / 兴奋 / 失落 / 委屈 / 难过 / 焦虑 / 害怕 / 生气 / 疲惫 / 孤独

### 3.2 深层情绪：表层 ≠ 深层

**例子**："你为什么这么久不回我？"
- 表面表达：抱怨、指责 → 表层情绪：生气 → 深层情绪：失落、害怕 → 依恋需要："我想知道自己对你是否重要"

猜测不一定正确，要让对方拥有修正你的空间：
- "你是不是有点……？""听起来你好像挺……的？"

### 3.3 辨的快速判断：需要 + 连接邀请 + 需求类型

**情绪背后的需要（7种）**：连接 / 被重视 / 安全感 / 被理解 / 被支持 / 被认可 / 自主

```text
事件 → 感受 → 某种需要没有得到满足
```

**识别连接邀请**：很多普通的话，不只是信息——它们可能是在问：**你愿意进入我的世界吗？**
- 转向（接住+延展）/ 转开（忽略）/ 对抗（反驳）
- 幸福夫妻 86% 转向，离婚夫妻 33%——不是大事件决定关系，是无数小互动积累

**判断需求类型（辨的最后一步，决定怎么展）**：

| 需求 | 信号 |
|---|---|
| **倾诉** | 反复描述事情、情绪明显、没问建议 |
| **分享** | 分享照片/日常/见闻 |
| **庆祝** | 开心、兴奋、分享好消息 |
| **被理解** | "你根本不理解我" |
| **建议** | "那你觉得我应该怎么办？" |
| **陪伴** | 不需要解决方案 |

> 辨到这一步，你就知道接下来该怎么"展"了。

---

## 四、接 —— 命名情绪，分水岭


### 接的三个层次

1. **命名情绪**：用陈述句说出对方的情绪——"听起来你今天挺累的"
2. **确认合理性**：让对方知道她的情绪是可以理解的——"换我我也会生气"
3. **表达在场**：让对方知道你在这里——"我在听""你说，我陪着你"

---

## 五、展 —— 按需求分叉回应

> "展"是最后一步，也是最灵活的一步。根据"辨"阶段判断的需求类型，选择不同的回应方式。
> 
> 不是所有情况都要解决问题，不是所有情况都要共情到底。

### 六种需求类型的回应方向

| 需求 | 回应方式 | 核心原则 |
|---|---|---|
| **倾诉** | 共情 + 好奇 + 继续听 | 不急着给建议，让她说完 |
| **分享** | 表达兴趣 + 参与她的世界 | 问细节、问感受，不急着转到自己 |
| **庆祝** | 和她一起开心，不分析 | 庆祝时不分析，分析会杀死快乐 |
| **被理解** | 先理解体验，不证明自己 | 不辩解、不证明自己没错 |
| **建议** | 先确认情绪，再分析建议 | 不替她做决定，给参考 |
| **陪伴** | 有人和她待在情绪里 | 在场就好，不硬拉她出来 |

## 六、最重要的原则

1. **先理解，再回应**——别一看到问题就回答，先问"她现在到底在表达什么？"
2. **情绪比逻辑先被接住**——对方情绪强时"你这样理解不对"无效，顺序是先确认感受→再理解原因→最后讨论事实。
3. **不要假装读心**——别说"我知道你就是害怕被抛弃"，留修正空间"你会不会有一点担心……？"
4. **共情 ≠ 解决**——她说"今天工作烦死了"，多数时候只需"听着就烦"，不是"那你应该辞职"。
5. **不要为了延展而延展**——目标不是让话题永远不断，是对方愿意连接时回应这份连接。
6. **庆祝时不分析**——对方分享好消息时，先一起开心，不要分析、不要建议。
7. **陪伴时不硬拉**——对方情绪低落时，在场就好，不要硬拉她出来。

## 七、实战流程总结

```text
听 ── 接事实，不评价，不急着回答
 │
 ▼
辨 ── 内部识别（对方看不到）
 │    ├─ 识别情绪（感受≠想法）
 │    ├─ 理解需要（7种关系需要）
 │    ├─ 深层情绪（表层≠深层）
 │    ├─ 连接邀请（转向/转开/对抗）
 │    └─ 判断需求类型（倾诉/分享/庆祝/被理解/建议/陪伴）
 │
 ▼
接 ── 命名情绪，确认合理性，表达在场（分水岭，对方能感受到）
 │
 ▼
展 ── 按需求分叉回应
      ├─ 倾诉 → 共情+好奇+继续听
      ├─ 分享 → 表达兴趣+参与她的世界
      ├─ 庆祝 → 和她一起开心，不分析
      ├─ 被理解 → 先理解体验，不证明自己
      ├─ 建议 → 先确认情绪，再分析建议
      └─ 陪伴 → 有人和她待在情绪里
```


> 学这些理论不是训练"高情商话术"，是形成能力——听见语言 → 看见情绪 → 理解需要 → 回应连接 → 共同创造对话。最终不是"我知道该说什么"，而是**「我大概知道，你现在需要我怎么在这里。」**
