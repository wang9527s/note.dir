# 01 总纲

> 沟通能力笔记。核心框架：**非暴力沟通四步法（观察→感受→需要→请求）** + **《亲密关系》沟通模型（编码→解码→反馈）**。
> 沟通不只是"会说话"，是让对方接收到你想传递的信息和情绪，并让对话流动起来。
> 结构：核心框架（02-03）→ 核心技能（04-05）→ 进阶技能（06）→ 场景应用（07）。

## 核心框架

**非暴力沟通四步法**（马歇尔·卢森堡）：
1. **观察**：客观事实，不评价
2. **感受**：情绪词，不想法
3. **需要**：背后的需求
4. **请求**：具体可执行

**沟通三层模型**（信息+情绪+邀请）：
- 信息层 = 事实（对应四步法的"观察"）
- 情绪层 = 感受（对应四步法的"感受"）
- 邀请层 = 把球抛给对方（对应四步法的"请求"）

## 核心理念


- **沟通的目的不是输出信息**，<font color='red'>是让对方有感受、想接话。</font>
- 平淡聊天 = 只交换信息（"吃饭了吗""在干嘛"）。
- 好沟通 = 信息 + 情绪 + 邀请对方参与。
- 冲突中：谈行为不谈人，说感受不说指责。
- <font color='red'>**用对方听得懂的语言去爱，不是用自己习惯的方式。**</font>
- 先接情绪，再接信息（所有场景通用）。<font color='red'>不要打断他人</font>
