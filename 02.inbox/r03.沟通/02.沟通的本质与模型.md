## 02 沟通的本质与模型

> **核心框架·沟通模型**。
> 理论来源：罗兰·米勒《亲密关系》沟通模型 + 实战总结。
> 沟通不只是"会说话"，是让对方接收到你想传递的信息和情绪，并让对话流动起来。

### 沟通的基本模型（《亲密关系》）

沟通不是"我说了什么"，是"对方接收到了什么"。

```text
发送者编码（我想表达的）→ 传递（说的话/表情/语气）→ 接收者解码（对方理解的）→ 反馈
```

**常见断点**：

| 断点 | 发生在哪 | 表现 |
|---|---|---|
| 编码错误 | 发送者 | 想的是A，说出来变成B |
| 传递损耗 | 传递中 | 文字丢情绪、语气被误读 |
| 解码错误 | 接收者 | 对方按自己的经验理解，和你想的不一样 |
| 反馈缺失 | 接收者 | 对方没回应，你不知道ta懂没懂 |

> 沟通出问题，多半不是"对方听不懂"，是某个断点没处理好。**检查自己的编码，确认对方的解码。**

### 信息 vs 情绪

<font color='red'>聊天聊死，多半因为只交换信息，没传递情绪。</font>

| | 信息 | 情绪 |
|---|---|---|
| 内容 | 事实、数据、状态 | 感受、态度、立场 |
| 例子 | "今天去看了个展" | "今天去看了个展，意外地挺戳我" |
| 对方接什么 | 也回信息（"哦什么展"） | 接情绪（"怎么戳了？"） |
| 结果 | 能聊但不热 | 有来有回，能深入 |

**信息是骨架，情绪是肉。** 只有骨架=干巴巴；只有肉=浮夸。两者都要。

> 每句话问自己：这句话带情绪了吗？对方接了能接什么？

### 表达的三层

1. **事实层**：发生了什么（信息）。
2. **感受层**：我对此什么感觉（情绪）。
3. **邀请层**：把球抛给对方（让对方有参与感）。

三层都到，表达才完整。

- 只到事实层："今天去看了个展。"（对方只能"哦什么展"）
- 到感受层："今天去看了个展，意外地挺戳我。"（对方能接"怎么戳了"）
- 到邀请层："今天去看了个展，挺戳我的，你平时看展吗？"（直接给对方接话位）

#### 邀请层的四种类型

> 邀请层不是单一把球抛回去——根据对方状态选不同邀请型，能让球抛得更准。详见 [06 接情绪基础](./06.接情绪基础.md)。

| 类型 | 触发场景 | 例子 |
|---|---|---|
| **邀请倾诉型** | 对方求被听见（情绪宣泄 / 示弱求助） | "跟我说说" / "怎么了" |
| **邀请确认型** | 对方求"我最重要"（吃醋 / 比较 / 最后通牒） | "你才是最重要的" |
| **邀请行动型** | 对方暗示期待（求你做到） | "我安排" / "那周末我……" |
| **邀请选择型** | 对方犹豫不定（"随便" / "看你"） | 给两个具体选项 |

### 表达侧 vs 回应侧（两套并行模型）

> 3 层模型（事实/感受/邀请）是**表达自己**的模型——主语是"我"。但"接对方情绪"是**回应侧**的操作，不在表达侧的三层里。两套并行，看句子在说谁就选哪套。

| 侧 | 模型 | 主语 | 出处 |
|---|---|---|---|
| **表达侧** | 3 层（事实/感受/邀请） | 我（说自己） | 《亲密关系》 |
| **回应侧** | 听—辨—接—展 + Validation | 你（接对方） | NVC 倾听模式 + Rogers 共情反映 + 戈特曼连接邀请 + 实战补丁 |

**区分点**：
- 句子主语是"我/自己" → 用表达侧 3 层（"我今天累瘫了，整个人空了，你呢？"）
- 句子主语是"你/对方" → 用回应侧（"你这是把自己否定了一顿啊"）

### 非暴力沟通四步法（表达侧·冲突场景）

> 三层表达在冲突/敏感场景的整合应用。理论来源：马歇尔·卢森堡《非暴力沟通》。
> **适用**：表达不满、提需求、谈敏感话题、对方情绪化时。不是每句话都套——轻松闲聊硬套反怪。

```text
观察（客观事实）→ 感受（情绪词）→ 需要（背后的需求）→ 请求（具体可执行）
```

四步对应三层：观察=信息层、感受=情绪层、需要+请求=邀请层。

**两个关键区分**

| | 暴力（评价/想法） | 非暴力（观察/感受） |
|---|---|---|
| 句式 | "你根本不在乎我" / "我觉得你很敷衍" | "你这周有三天没主动找我" / "我感到失落" |
| 性质 | 主观判断、贴标签、指向对方 | 客观可验证、情绪词、指向自己 |
| 对方反应 | 防御、反驳 | 能听进去 |

> 翻译公式：把"我觉得你[形容词]"换成"我感到[情绪词]"。"你很敷衍"→"我感到失落"；"你很自私"→"我感到委屈"。
> 请求≠命令：请求允许拒绝（"能不能每天下班发个消息"），命令不许（"你必须每天找我"）。

**倾听侧**：对方发火时，背后是没被满足的需要——**别接情绪，找需要**。复述确认"你是说……所以你感到……？"。

> 核心：每一步替换"你"开头的指责，换成"我"开头的感受和需要。指责推对方走，需要拉对方近。冲突中：谈行为不谈人，说感受不说指责。

### 节奏感

<font color='red'>沟通好坏，节奏比内容重要。</font>

- 别一次说太长（长篇=对方没插嘴位=单向输出）。
- 一句一停，看对方反应再继续。
- 对方冷淡就收，对方热就继续——别自顾自讲。
- 留白也是一种表达，沉默比硬填强。

> <font color='red'>沟通高手不是说得最多的人，是让对方说得最多的人。</font>

### 文字 vs 语音 vs 见面

- **文字**：情绪靠用词和标点（"！" "……" emoji），但易被误读。重要情绪别只用文字。
- **语音**：带语气，情绪传递强，但别长语音轰炸。
- **见面**：表情、语气、肢体全有，情绪传递最准。敏感话题优先见面。
