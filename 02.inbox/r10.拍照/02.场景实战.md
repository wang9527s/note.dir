# 场景实战

> 不同场景的具体拍照方法。每个场景给出：推荐姿势、构图技巧、光线建议、注意事项。

## 1. 旅行风景照（山顶/瀑布/海边/古城）

### 1.1 山顶/开阔风景

**参考视频**：[旱地拔葱拍照姿势](https://www.douyin.com/video/7677800424900161222)（莹莹出片机）

![旱地拔葱示例](./images/01-旱地拔葱.jpeg)

![仰拍风机示例](./images/02-仰拍风机.jpeg)

**推荐姿势：**
- "旱地拔葱"：背对镜头站在岩石/台阶高处，双臂张开或自然下垂
- 侧对镜头，回头看镜头，一只手插兜
- 坐在岩石边缘，双腿自然下垂，看远方

**构图技巧：**
- 人物放画面下1/3，天空/风景占上2/3
- 利用山脊线/海岸线做引导线
- 前景可以放一些岩石/草，增加层次

**光线建议：**
- 黄金时刻（日出/日落）最佳，天空有颜色
- 正午顶光避免，人物脸上有阴影

**注意事项：**
- 安全第一，不要站在危险边缘
- 风大时头发会乱，可以戴帽子/扎头发

### 1.2 瀑布/水景

**参考视频**：[瀑布踏浪动态抓拍](https://www.douyin.com/video/7669429701082231739)（梦乐丫）

![瀑布踏浪示例](./images/04-瀑布踏浪.jpeg)

**推荐姿势：**
- 站在瀑布前，伸手接水/玩水，动态抓拍
- 背对镜头，看瀑布，双臂自然张开
- 坐在水边石头上，脚泡水，放松姿态

**构图技巧：**
- 瀑布做背景，人物放黄金分割点
- 利用水流的线条引导视线
- 可以慢门拍水流（手机专业模式/夜景模式），水流丝滑

**光线建议：**
- 瀑布附近通常光线较暗，注意拉亮曝光
- 水雾大时可能有彩虹，抓住机会

**注意事项：**
- 地面湿滑，注意安全
- 防水：手机装防水袋，不要离水太近
- 危险动作（走绳索/跳瀑布）不要模仿

### 1.3 海边
**推荐姿势：**
- 光脚踩水，走路动态抓拍
- 背对镜头，看海，头发被风吹
- 坐在沙滩上，双腿弯曲，手撑在身后
- 跳起来，抓拍腾空瞬间

**构图技巧：**
- 海平线放上1/3或下1/3，不要放中间
- 利用沙滩纹理/海浪线条做引导线
- 前景可以放贝壳/脚印/椰子

**光线建议：**
- 日落时分最佳，天空橙红色，海面反光
- 逆光拍剪影也很好看

**注意事项：**
- 防晒！海边紫外线强
- 手机防沙防水
- 涨潮注意安全

### 1.4 古城/古建筑

**参考视频**：[西安城墙8个万能拍照姿势](https://www.douyin.com/video/7671454967425729521)（西安摄影师-微笑）

![西安城墙示例](./images/03-西安城墙.jpeg)

**推荐姿势：**
- 靠在城墙/柱子上，一只脚蹬墙，手插兜
- 走在古城街道上，回头抓拍
- 利用门框/窗框做框架构图，人物站在框里
- 穿古风/汉服/新中式衣服更搭

**构图技巧：**
- 框架构图：用城门/窗框/拱门框住人物
- 对称构图：站在中轴线，建筑对称
- 利用城墙砖的纹理做背景

**光线建议：**
- 清晨/傍晚人少，光线柔和
- 利用建筑的阴影创造明暗对比

**注意事项：**
- 游客多，早起或晚去避开人流
- 不要触摸/攀爬文物
- 衣服颜色和建筑搭配（红墙配白/黑/金）

## 2. 城市夜景/约会照

### 2.1 城市夜景

![情人节约会示例](./images/05-情人节约会.jpeg)

**推荐姿势：**
- 靠在栏杆上，看城市夜景，侧脸
- 走路动态抓拍，背景车灯拖影
- 利用路灯/霓虹灯做光源，人物在光下

**构图技巧：**
- 前景虚化（用花/树叶/栏杆），背景城市灯光虚化（光斑）
- 人物放黄金分割点，背景留空
- 利用道路/桥梁线条做引导线

**光线建议：**
- 路灯/霓虹灯做光源，不要用闪光灯（闪光灯会破坏夜景氛围）
- 手机点按人脸对焦+拉亮曝光
- 黄金时刻刚天黑时（蓝调时刻）最佳，天空还有蓝色，灯光已亮

**注意事项：**
- 夜景手机容易糊，拿稳手机或靠在栏杆上
- 用人像模式背景虚化更好看
- 注意安全，不要在马路上拍

### 2.2 情人节约会/有花的场景

**参考视频**：[情人节约会拍照构图技巧](https://www.douyin.com/video/7675556744459143529)（秋秋脾气好）

![约会构图示例](./images/05-情人节约会.jpeg)

**推荐姿势：**
- 拿花挡半脸/闻花/举花
- 和花互动，花做前景
- 靠在窗边/栏杆，看远方

**构图技巧：**
- **前景+背景层次**：离花一臂距离，花做前景（虚化），人物在中间，夜景/风景做背景
- 花不要挡住脸，放在脸侧/胸前
- 人物放黄金分割点

**光线建议：**
- 暖光（路灯/餐厅灯）更有氛围感
- 不要用白光/荧光灯，脸色发青

**注意事项：**
- 花的颜色和衣服搭配
- 不要让花完全挡住脸
- 自然互动，不要刻意摆拍

## 3. 朋友聚会/多人照

### 3.1 朋友聚会

![机场扶梯示例](./images/06-机场扶梯.jpeg)

**推荐姿势：**
- 不要都看镜头——有人看镜头、有人看旁边、有人互动（聊天/笑/碰杯）
- 排列站位：高低错落，不要站成一排
- 利用桌子/沙发/栏杆，有人坐有人站
- 动态抓拍：一起走路/回头/跳起来

**构图技巧：**
- 利用环境排列：扶梯（前后站）、台阶（高低站）、走廊（纵深排列）
- 引导线：扶梯扶手/走廊线条引导视线
- 不要把人裁掉，全身照要拍到脚

**光线建议：**
- 室内聚会注意光线，靠窗位置最佳
- 多人照不要用闪光灯（有人会闭眼）

**注意事项：**
- 每个人都要在画面里，不要有人被裁
- 自然互动最出片，不要都僵硬看镜头
- 连拍，总能抓到大家都好看的

### 3.2 机场/车站/公共场所

**参考视频**：[机场扶梯朋友拍照](https://www.douyin.com/video/7677601443591774385)（月亮能有什么错）

**推荐姿势：**
- 扶梯上：前后站，有人回头，有人看前方
- 走廊里：一起走路，动态抓拍
- 大窗户前：利用窗外风景做背景，剪影/侧影
- 行李箱做道具：坐在行李箱上/拉行李箱走路

**构图技巧：**
- 引导线：扶梯扶手/走廊线条/地砖线条
- 框架构图：用窗户/门框框住人物
- 利用公共场所的线条和几何感

**光线建议：**
- 机场/车站通常是顶光，注意找侧面光源（窗户）
- 大窗户前逆光拍剪影很好看

**注意事项：**
- 不要影响他人，快速拍完就走
- 注意行李和贵重物品
- 安检区/限制区域不要拍

## 4. 日常抓拍/生活照

### 4.1 日常抓拍
**推荐姿势：**
- 做日常事情：喝咖啡、看书、走路、买东西、等红绿灯
- 不看镜头，自然做自己的事
- 回头抓拍：叫名字，回头的瞬间

**构图技巧：**
- 抓拍为主，构图可以后期裁剪
- 利用环境元素（街道/咖啡店/书店）做背景
- 留白：人物朝向的方向多留空

**光线建议：**
- 窗边/门口的自然光最佳
- 避免顶光和荧光灯

**注意事项：**
- 连拍，抓自然瞬间
- 不要让被拍的人发现（发现了就不自然了）
- 尊重他人，不要拍陌生人

### 4.2 自拍
**推荐姿势：**
- 俯拍45度：显脸小，手机举高
- 对镜自拍：利用镜子，拍全身/半身
- 他拍视角：手机放远处，定时拍摄，假装别人拍的

**构图技巧：**
- 俯拍时人物放画面下方，上方留空
- 对镜自拍：镜子做框架，人物在中间
- 利用前景（手/杯子/花）挡一部分，增加层次

**光线建议：**
- 面对窗户/光源，脸亮
- 不要背光，不然黑脸

**注意事项：**
- 手机不要挡住脸
- 自然表情，不要假笑
- 对镜自拍注意镜子里的背景（不要乱）

## 5. 场景选择速查表

| 场景 | 最佳姿势 | 核心技巧 | 避坑 |
|---|---|---|---|
| 山顶/开阔地 | 旱地拔葱（背对张开） | 人物放下1/3，风景占2/3 | 正午顶光、危险边缘 |
| 瀑布/水景 | 玩水动态抓拍 | 水流引导线、慢门拍丝滑 | 地面湿滑、手机进水 |
| 海边 | 踩水走路/跳起来 | 海平线不居中、日落逆光 | 防晒、涨潮 |
| 古城/建筑 | 靠城墙/框架构图 | 门框窗框做框架、对称构图 | 游客多、攀爬文物 |
| 城市夜景 | 靠栏杆看夜景/走路 | 前景虚化+背景光斑、蓝调时刻 | 闪光灯、手抖糊片 |
| 约会/有花 | 拿花互动/花做前景 | 前景花+背景夜景层次 | 花挡脸、白光 |
| 朋友聚会 | 互动不看镜头/高低错落 | 扶梯台阶排列、引导线 | 站成一排、有人被裁 |
| 机场/公共场所 | 扶梯前后站/大窗户剪影 | 引导线、框架构图 | 影响他人、安检区 |
| 日常抓拍 | 做日常事/回头瞬间 | 连拍、留白 | 摆拍僵硬、拍陌生人 |
| 自拍 | 俯拍45度/对镜自拍 | 举高显脸小、前景挡一部分 | 手机挡脸、背光黑脸 |
