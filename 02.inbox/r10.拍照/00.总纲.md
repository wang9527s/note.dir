# 拍照技巧总纲

> 来源：抖音拍照技巧视频汇总（旱地拔葱、西安旅游拍照、情人节约会构图等）+ 通用摄影知识。
> 核心：普通人用手机也能拍出好照片，关键是**利用环境+构图+姿势+光线**，不需要专业器材。

## 核心思路

| 维度 | 关键 | 常见错误 |
|---|---|---|
| **构图** | 利用前景/背景/引导线，人物放黄金分割点 | 人物居中、画面太满、没有层次 |
| **角度** | 仰拍显高显气场，俯拍显可爱，平拍自然 | 全程平视、从下往上拍双下巴 |
| **姿势** | 动态抓拍、利用道具、手脚有动作 | 站军姿、剪刀手、手脚僵硬 |
| **光线** | 顺光清晰、侧光有立体感、逆光有氛围感 | 逆光拍黑脸、顶光拍阴影 |
| **环境** | 利用场景特色（瀑布/城墙/风机/机场） | 随便找个白墙就拍 |

## 视频来源汇总

| 视频 | 核心技巧 | 适用场景 |
|---|---|---|
| 旱地拔葱（莹莹出片机） | 背对镜头站高处+双臂张开，利用风景背景 | 山顶、瀑布、海边等开阔风景 |
| 别抬头它正在压下来（谭浪） | 仰拍+大型物体（风机）创造视觉冲击力 | 风力发电机、高楼、大树等高大物体 |
| 西安城墙8个万能姿势（西安摄影师微笑） | 8个旅行打卡万能姿势 | 古城墙、古建筑、旅行景点 |
| 瀑布踏浪（梦乐丫） | 利用水景+动态动作创造松弛感 | 瀑布、海边、溪流等水景 |
| 情人节约会构图（秋秋脾气好） | 利用前景（花）+背景（夜景）的层次构图 | 约会、城市夜景、有花/植物的场景 |
| 机场扶梯拍照（月亮能有什么错） | 利用公共场所（扶梯/机场）+朋友互动 | 机场、商场、地铁站等公共场所 |
