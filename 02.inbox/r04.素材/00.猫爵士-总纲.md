## 核心概念速查

| 概念 | 一句话 |
|---|---|
| 张力效应 | 你越推关系，关系越倒退。增加她的确定性=负向张力，增加自己的确定性=正向张力 |
| 能量吸引 | 高能量者吸引低能量者。把能量放自己身上，不是放对方身上 |
| 顺其自然 | 行为上主动，心态上放下，结果上接受。不是什么都不做 |
| 上头下头 | 你越上头，她越下头。上头时的行为都是错的 |
| 备胎机制 | 用"对她好"接近她=备胎。要用"吸引"接近 |
| 自我效能感 | 相信自己有能力处理情况，自信的本质 |
