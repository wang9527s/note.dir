## 02 三角理论 — 爱情由什么构成

### 基本概念

**亲密（Intimacy）**：亲近、理解、连接、信任、情感依恋  
**激情（Passion）**：<font color='red'>浪漫吸引、身体/性吸引，以及促使人靠近对方的动机</font>  
**承诺（Commitment）**：决定爱一个人，以及决定维持这段关系的意愿

### 亲密 Intimacy：“我和你很近”

核心不是“喜欢”，而是心理距离缩短。

| 子维度 | 具体是什么 |
|---|---|
| **了解** | 知道对方的经历、性格、习惯、想法 |
| **理解** | 能理解对方为什么这么想、这么做 |
| **信任** | 愿意暴露脆弱、不太担心被伤害 |
| **自我暴露** | 愿意分享私人经历、秘密、真实想法 |
| **情绪连接** | 对方的情绪会影响自己 |
| **被理解感** | 感觉“她真的懂我” |
| **依赖** | 遇到事情会自然想到对方、希望得到对方回应 |
| **归属感** | 开始产生“我们”的感觉 |
| **共同经历** | 两个人形成别人没有的共同记忆 |

### 激情 Passion：“我想靠近你，而且是恋爱意义上的靠近”

这个就是这次最值得研究的部分。

“没有恋人般的心动”其实就是非常直接地指向这个维度。

**广义眼缘也可以看作激情形成的前置因素。**

| 子维度 | 具体是什么 |
|---|---|
| **浪漫吸引** | 想把对方当作恋爱对象 |
| **身体吸引** | 想靠近、拥抱、触碰等 |
| **性吸引** | 性方面的兴趣和冲动 |
| **兴奋/心动** | 见到对方会产生特殊的情绪唤起 |
| **期待** | 会期待下一次见面、消息 |
| **接近动机** | 不只是“愿意见”，而是“想见” |
| **特殊性** | 对方不是普通朋友，而是“这个人” |
| **浪漫幻想** | 自然产生情侣关系的想象 |
| **占有/排他倾向** | 对对方与其他异性的关系产生特殊敏感 |
| **恋爱动机** | 会产生“我想和她谈恋爱”的念头 |

### 承诺 Commitment：“我决定把你放进我的长期关系里”

承诺不等于“三观”。

三观、价值观、生活方式等可以影响关系选择，但承诺本身更接近于**选择关系并愿意维持关系**。

| 子维度 | 具体是什么 |
|---|---|
| **关系意愿** | 愿意正式进入恋爱关系 |
| **选择** | 在多个可能性中选择这个人 |
| **排他性** | 愿意放弃其他潜在关系 |
| **长期意愿** | 愿意考虑长期发展 |
| **责任感** | 愿意承担关系中的责任 |
| **稳定投入** | 愿意持续投入时间、精力、情绪 |
| **困难承受能力** | 出现问题后愿意解决而不是直接退出 |
| **未来规划** | 开始把对方纳入未来计划 |
| **关系身份** | 从“我和她”变成“我们” |
