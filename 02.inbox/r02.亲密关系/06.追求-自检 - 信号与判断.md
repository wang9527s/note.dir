## 06 追求-自检 — 信号与判断

> 追求期判断：该不该推进、对方有没有兴趣、何时该退。
> 机制见 [04 追求-理论](./04.追求-理论%20-%20互动机制.md)，行动见 [05 追求-实战](./05.追求-实战%20-%20从认识到确认.md)。判断对方兴趣看行为，别靠猜。

## 6.1 初期自检

- [ ] 有线下见面，不只是线上聊？（线上聊再热，没见面就是虚的）
- [ ] 见面有轻度情绪唤醒/共同体验，不是纯吃饭聊天？（共同体验才养激情）
- [ ] 暴露分层推进，没有一次倒完？（一次倒完=熟人模式，透支后续）
- [ ] 线上亲密没跑在线下激情前面？（亲密远超激情=变朋友）
- [ ] 对方有对等回应，不是单向投入？（单向2-3轮无回流=没兴趣）

→ 全是：可推进。有否：先补该项再观察。

## 6.2 节奏：兴趣信号与应对

**对方兴趣信号**

| 有兴趣（多条命中） | 没兴趣/在减退 |
|---|---|
| 主动发起聊天/约见面 | 只回不发起，从不主动 |
| 回复有内容、有追问 | 回复敷衍（短、慢、不追问） |
| 见面结束主动提下次 | 推脱见面，不主动改期 |
| 你分享后ta也分享、越来越深 | 暴露不回流，只回表面 |
| 对你区别对待（更上心） | 见面冷淡（手机比你有吸引力、身体后仰） |
| 身体语言（朝向、眼神、不抗拒靠近） | |

**在犹豫（边界信号）**：回得慢但认真 / 见面热情线上冷淡（或反之）/ 偶尔主动但不持续。
→ 给空间，降速观察，别加码施压。2-3 周无自然回流，按"没兴趣"处理。

**没兴趣的应对**（看程度）

| 程度 | 处理 |
|---|---|
| 低能量（回复变短、话题难延续） | 自然结束，不强行续聊 |
| 退缩（持续敷衍、主动性下降） | 降频率，给空间，观察是否重新靠近 |
| 持续回避/反感（多次拒见、明确不想发展） | 尊重边界，停止推进，体面退出 |

## 6.3 警戒线

自己节奏的危险信号：

- 线上聊到"很熟很聊得来"但没见面 = 危险，立刻补线下。
- 见面体验差 = 先修体验再约，别硬约下一次。

## 6.4 确认前后自检（表白前）

- [ ] 对方主动发起聊天/邀约？（只回不发起=没兴趣）
- [ ] 回复有质量、有追问？（敷衍=减退）
- [ ] 见面有身体语言信号（朝向、眼神、不抗拒靠近）？
- [ ] 暴露双向回流？
- [ ] 有"下次一起"的期待？
- [ ] 双方都明确恋爱意愿，不是一方在等一方在猜？（猜=没到位）
- [ ] 激情+亲密都有，不是只有"很合得来"？（合得来是亲密，缺激情别确认）
- [ ] 没有为"怕失去"而仓促确认？（怕失去=焦虑驱动，不是想清楚）

→ 多条命中：适合表白/确认。信号命中少：回去继续养，别急着表白。缺激情：回去补激情。

## 6.5 怎么确认对方心意（持续行为，不是单次）

别靠"猜"，看行为模式（不是单次，是持续）。

**爱的迹象（持续存在）**

- 主动投入时间精力（不是你催的）
- 记得你说过的小事（在意才会记）
- 在意你的感受，愿意调整（不是嘴上说改）
- 把你纳入未来计划（口头+行动）
- 危机时的反应（病了、出事了，ta在不在）
- 排他性（主动与其他异性保持边界）

**别只看**

- 甜言蜜语（成本低）
- 单次大动作（可能表演）
- 对方怎么说（看怎么做）

> 确认一个人爱不爱你，看**持续的、付出成本的、行动层面的**信号，不是一时的情绪和话术。

## 6.6 确认关系的男女差距

**节奏差**
- 男性往往先有感觉→再慢慢确认要不要负责
- 女性往往先确认关系→再投入更多感情
- 双方在"确认"这个点上的心理状态不同步，容易误读

**需求差**
- 男性确认"被需要、被尊重"→愿意承诺
- 女性确认"被在乎、有安全感"→愿意投入
- 他需要感到"她认可我"，她需要感到"他选了我"

**表达差**
- 男性可能用"承诺+行动"表达确认（介绍给朋友、规划未来、排他）
- 女性可能用"情绪开放+依赖"表达确认（倾诉脆弱、主动亲近、要陪伴）
- 各自表达确认的方式不同，对方没接收到=以为没确认

**核心原则：口头明确 > 默契猜。** 猜默契最易翻车。
- 直接问："你觉得我们现在算什么关系？"
- 直接说："我想和你正式在一起。"
- 别靠"都这样了应该算吧"来确认。
