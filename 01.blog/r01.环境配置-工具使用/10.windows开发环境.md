### 1、Windows启动nfs server

[winnfsd](https://github.com/winnfsd/winnfsd)

```bash
# win启用nfs server
.\WinNFSd.exe D:\nfs\nfs_share_server /win_nfs

# linux（client）挂载到刚刚的server上
mkdir /mnt/sdcard/nfs/
mount -t nfs -o nolock,nfsvers=3,vers=3 192.168.31.213:/win_nfs /mnt/sdcard/nfs/
```
