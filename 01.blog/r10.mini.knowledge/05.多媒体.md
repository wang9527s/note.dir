### 下载bilibili视频

google 商店下载 Get cookies.txt插件

然后获取cookies.txt

```bash
# windows           pip install yt-dlp 
# ubuntu 20.04      sudo apt install yt-dlp
# 只需要视频链接的前半部分即可
yt-dlp --cookies .\www.bilibili.com_cookies.txt "https://www.bilibili.com/video/BV1zbCrBdEYA"
```

### ffmpeg 视频处理

```bash
# 截取某段视频 (重新编码)
ffmpeg -i input.mp4 -ss 00:10:30 -t 00:00:52 output_1.mp4

# 截取某段视频 (流拷贝，更快，不重编码)
.\ffmpeg.exe -ss 00:00:00 -i "D:\2024-04-10 00-04-08.mkv" -t 00:00:06 -c:v copy -c:a copy "D:\t.mkv"

# 裁切视频画面 (crop，去掉边缘)
.\ffmpeg.exe -i "D:\t.mkv" -vf "crop=1420:in_h:0:0" -c:v libx264 -crf 23 -preset medium -c:a copy "D:\t2.mkv"

# mp4转gif
.\ffmpeg.exe -i .\out_3x.mp4 -c:v gif out.gif
.\ffmpeg.exe -i .\5.mp4 -vf "scale=1920:-1:flags=lanczos" -c:v gif 5.gif

# 视频转为2倍速（注意，视频时长和音频速度无变化）
# 我对结果进行截取，获取想要的片段
.\ffmpeg.exe -i .\1.mp4 -filter:v "setpts=0.5*PTS" -c:a copy out_3x.mp4

# 压缩音频
ffmpeg -i input.m4a -c:a aac -b:a 64k output.m4a
```

### 音视频转文字

```bash
# --break-system-packages 并不会真的破坏系统
pip3 install --user openai-whisper --break-system-packages -i https://pypi.tuna.tsinghua.edu.cn/simple/ 
# 音视频文件 转文字
python3 -m  whisper output_1.mp4 --language zh  --output_format txt  --model base
```

### 图片处理

```bash
# 压缩png/jpg -> jpg
convert 1102-5.png -resize 80% -strip -sampling-factor 4:2:0 -quality 40 1102-5.jpg

# png->webp
cwebp -lossless ./event-02.png -o ./event-02.webp

# jpg->jpg
convert 1208-smile.JPG -resize 50% -quality 95 temp.jpg

# png->png  （聊天记录用着比较好）
pngquant --quality=90-100 --speed=1 --strip --force 0520-1.png --output out0520-1.png

# 分割图片  除最后一个 每个图片的1688像素 
convert inpout.jpg -crop x1688 +repage out_%02d.jpg
# x1688 裁切为上下几张图
# 1688x 裁切为左右几张图

# 裁切中间某部分图片 y坐标90开始，裁切掉高度为360的区域
convert 01.png -chop 0x360+0+90 result.png
```
